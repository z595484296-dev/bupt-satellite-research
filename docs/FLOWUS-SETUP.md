# FlowUs → 官网自动同步

更新：2026-10-21。已通过官方 FlowUs CLI 的浏览器授权连接真实空间 iThinker，每 5 分钟检查并自动发布，无需逐篇审核。已同步 15 篇观点和 20 条中心动态的正文及图片、附件；网站使用本地文件地址展示内容。动态本批包含 38 张不同图片，没有附件。

## 当前已确认的公开范围

- 内容依据是空间「对外开放 → 中心推广 → 卫星互联网研究中心」公开入口，而不是整个团队空间。公开入口包含中心简介、中心观点、中心动态、行业政策、行业新闻与动态。
- 观点来源：光子评论多维表 `a3fb765a-8b68-487a-916b-9fe17d14d58d`，对应网站「观点洞察」。仅同步单选字段「状态」精确等于「研究中心」的记录；目前为 15 篇。其余「写作中」「已完成」记录不导入。
- 动态来源：多维表 `e093dee2-c334-4903-bb11-0260e2a014fd`，对应网站「中心动态」。仅同步多选字段「类型」包含完整标签「中心动态」的记录；目前为 20 条。带有多个标签也会匹配，只标为团队分享等其他类型的 15 条记录不导入。连同网站已有的成立动态，当前动态栏目共 21 条。
- 行业政策与行业资讯引用共用多维表，目前未接入。已从公开页面筛选菜单核实「行业政策」条件为「关联项目包含行业政策【中心】」，行业新闻视图条件仍待核实；连接器尚未支持这两个视图的关联筛选。中心简介目前仍由网站「站点信息」维护，尚未实现简介自动同步。
- 导师在上述已接入范围内更新内容，下一轮成功同步后自动更新网站；观点状态改为其他值，或动态移除「中心动态」标签时，对应的已同步文章自动下架。新增符合条件的记录也会自动导入。
- 当前本机无需再填写密钥。网站通过 CLI 使用已经完成的浏览器授权；CLI 保管和续期 OAuth 凭据，网站不复制或返回凭据。

## 你需要配置什么

已登记的内容目录：
https://flowus.cn/ithinker/ee799fdd-e50f-4f7f-b574-295447b5edec

1. 当前本机已经配置 CLI 浏览器授权，直接使用即可。新服务器可安装官方 CLI，在服务账号下完成浏览器授权，并配置下文的 CLI 路径、私有授权目录与目标空间 UUID。已有有效 API 访问令牌时，也可选择令牌模式。两种方式择一。
2. CLI 模式不需要粘贴密钥；令牌模式需要可用于 FlowUs V2 Bearer 认证的访问令牌，不能把分享码或未经验证的应用客户端密钥当成访问令牌。凭据只保存在服务端，不放在前端或聊天里。
3. 登录网站 `/admin`，打开「FlowUs 同步」。当前本地预览地址从 `.runtime/connection.json` 读取；不要把开发预览地址当成已上线的公网域名。
4. 点击「测试连接」，然后「识别已保存的目录」。目录识别只列出页面/多维表，不会把主页发布成文章。添加需要的来源，选择「观点洞察」「研究与成果」或「中心动态」。中心简介目前仍在「站点信息」维护，不要把简介误加为观点文章。
5. 本项目使用「仅匹配指定状态或标签的记录」：观点字段为「状态」、匹配值为「研究中心」；动态字段为「类型」、匹配值为「中心动态」。单选/状态字段按值精确匹配，多选字段按完整标签是否存在匹配。其他来源也支持「仅勾选发布的记录」（默认复选框列名「官网发布」）或「整表同步」。混有内部内容的多维表应明确筛选范围；当前不要改成整表同步。这是一次性的范围设置，不是逐篇审核流程。
6. 保持「每 5 分钟」「同步成功后自动发布」，保存配置后点击「立即同步」。状态区会显示发布、未变化、待处理、下架与错误记录。

后续导师继续在 FlowUs 编辑。网站无需人工复制正文。当前电脑关闭或 Node 服务停止后不会继续检查；部署阿里云后由常驻 Node 服务承担同步。

官方参考：[创建内部集成](https://flowus.cn/share/07168d83-cb08-4ab8-ab73-74fe915054b1)、[认证与权限](https://flowus.cn/developer-api/v2/zh/getting-started/authentication-and-scopes)、[当前身份](https://flowus.cn/developer-api/v2/zh/read/get-current-identity)。指南中的旧版 API 示例不用于本项目，连接器使用 V2。

## 已实现的内容行为

- 网站原生 Markdown 排版：段落、标题、强调、列表、引用、代码、表格、链接、文内图片；无需嵌入 FlowUs 页面。
- 图片下载后保存在网站。支持 PNG/JPEG/WebP/GIF/AVIF；附件支持 PDF/DOCX/XLSX/PPTX，展示名称、类型和大小，通过本站下载。
- 正文里的文件块与多维表「文件」属性均会收集。FlowUs 临时下载地址不会作为图片/附件的长期公开地址。
- 已有四篇观点通过源页面 UUID 匹配，沿用当前文章 ID。已有封面、推荐设置和未在 FlowUs 提供的元数据会保留。
- 自动读取标题；可选属性按精确列名映射：摘要、作者、分类、发布日期。动态的「分类」为空时使用「活动类型」，发布日期为空时使用「时间」日期列。文本、单选与多选字段均可读取，多位作者以顿号分隔；斜线日期统一为 `YYYY-MM-DD`。不会把「分享者/受访者」当成作者。不存在/空值会保留网站旧值，清空旧元数据需在网站内容库操作。
- 自动模式每轮完整核对正文及文件摘要；内容未变化不重复发布。每个来源的栏目在首次导入时决定，已存在的文章保留原栏目。
- 使用复选框模式时取消勾选、使用状态匹配时改为其他状态、使用多选匹配时移除指定标签，或读取到明确的 `in_trash`，下次成功同步会把对应文章转为草稿。删除发布字段或更改为不支持的字段类型会报错并保留已发布版本。单纯移出多维表、删除来源配置、401/403/404 或网络错误不会被猜成删除；此时后台提示，网站保留已发布版本，可手动下架。
- 文件失效、下载失败、正文超过限制、含 HTML/不支持的嵌入块等会阻止该篇更新，并保留上一版。需要处理的候选与预览仅管理员可见。支持的普通文章不需要审核。
- 默认自动发布；后台仍保留可选手动预览模式。手动发布会重新读取来源校验，并检查网站版本冲突。

## 边界与限制

- 当前为 FlowUs 单向读取到网站，不回写导师的页面。
- 支持指定单篇页面和多维表。目录识别查找当前目录及其排版容器中的页面/多维表，并从官方 Markdown 导出补充内嵌多维表链接，逐个验证其 ID。识别到的来源须明确添加并设置公开范围，不会自动变成公开文章。对子目录可单独设置其目录链接再识别。
- 思维导图、第三方嵌入、音视频、HTML、复杂交互块不能直接复刻；检测到导出占位内容时停止发布，需先在 FlowUs 转成普通图文。不是所有 FlowUs 编辑器效果都能等同转换。
- 限制：最多 20 个来源、每个多维表 200 条记录、正文 50,000 字符、每篇 50 个文件、单文件 20 MB、每篇文件合计 100 MB。超过限制会报错，不截断发布。
- 同步读取整个多维表，不使用画廊/视图的筛选器作为公开边界；应明确选择状态匹配、复选框或专用公开表。视图 ID 不能代替多维表 ID。
- 批次逐篇更新，单篇失败不影响其他成功文章；不是整站一次性的事务快照。
- 备份位于 `DATA_DIR/backups`，并保留最近 50 条发布历史；尚无一键回滚界面。恢复备份前停服务，再恢复整个匹配的内容/文件备份。

## 服务器配置与部署

当前本机采用 CLI 模式，在私有 `.env` 中设置：

```dotenv
FLOWUS_AUTH_MODE=cli
FLOWUS_CLI_PATH=/absolute/path/to/flowus
FLOWUS_CONFIG_DIR=/absolute/private/path/to/flowus-profile
FLOWUS_WORKSPACE_ID=<authorized workspace UUID>
```

路径须使用所在操作系统的绝对路径，CLI 的授权空间必须与配置一致。CLI 模式忽略 `FLOWUS_TOKEN`，网站仅允许固定的读取接口，查询多维表使用的 POST 也仅用于读取。不会创建或修改 FlowUs 页面。若授权失效、撤销或切换了空间，后台会报告错误并保留最后成功同步的内容；需要在对应服务器服务账号下重新授权。

令牌模式不设置 `FLOWUS_AUTH_MODE=cli`，通过后台保存有效访问令牌到 `DATA_DIR/flowus-private.json`，或使用优先级更高的服务器环境变量 `FLOWUS_TOKEN`。API 只返回是否配置，不返回令牌值。`npm run dev` 和 `npm start` 自动加载存在的 `.env`；更改环境变量后需重启。`.env.example` 仅为模板。

不要将 `data/`、`.runtime/`、`.env` 或备份目录放进公开静态目录或源码包。该版本的全部同步功能需要运行 `server/index.mjs`；只部署 `dist/client/` 或静态 Sites worker 不会产生后台同步能力。

阿里云部署沿用 README：单个 Node 进程、持久磁盘、进程守护、HTTPS 反向代理、`COOKIE_SECURE=true`。CLI 模式还需在服务器安装相应系统版本的官方 CLI，并为服务账号配置私有、持久的授权目录；本机已登录不代表云服务器已经授权。当前尚未部署云服务器。不要让多个进程同时写同一 JSON 数据目录。需要多实例时应先迁移事务数据库和分布式任务锁。服务器需访问 `api.flowus.cn:443` 以及附件的公开 HTTPS 存储域名。

连接器仅对官方 API 使用认证；下载文件不携带密钥。FlowUs 官方 CDN 请求带来源 Referer，以适配其文件访问要求。文件下载拒绝私网、环回、保留地址和非 HTTPS，检查重定向与实际连接地址，并限制大小和文件类型。正文普通引用链接可保留 HTTP/HTTPS/mailto，但不会因普通引用链接而下载远程资源。待发布文件通过认证接口预览；同步文件仅在有已发布文章引用时对外提供。
